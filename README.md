# InterBar (Paper / Spigot 1.16.5 - 26.x)

Скорборд справа (сторінки, анімований заголовок), боссбар, TAB, ранги.

- Збірка: `mvn clean package` -> `target/InterBar.jar` -> папка `plugins/`
- Команди: `/bar` (меню), `/bar toggle <sidebar|bossbar|tab>`, `/bar reload`
- Все налаштовується в `config.yml`
